## 🔧 Configuration Quick Reference

All configuration in `app_new_faster.py` (lines ~109-150):

```python
# Pause thresholds (seconds)
SHORT_PAUSE_SEC = 2.0
MEDIUM_PAUSE_SEC = 5.0
LONG_PAUSE_SEC = 10.0
VERY_LONG_PAUSE_SEC = 20.0

# Filler thresholds (fillers per 100 words)
MAX_FILLERS_EXCELLENT = 2
MAX_FILLERS_GOOD = 5
MAX_FILLERS_FAIR = 10

# Deduction amounts (points)
PAUSE_DEDUCTION_SHORT = 2
PAUSE_DEDUCTION_MEDIUM = 5
PAUSE_DEDUCTION_LONG = 10
PAUSE_DEDUCTION_VERY_LONG = 15
BASE_SCORE = 90
```

See: QUICK_START.md (Customizing Thresholds section)
